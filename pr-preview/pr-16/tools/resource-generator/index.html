What it does

A district has decided what to teach. Now it has to explain that decision to a school board, to families, and to students choosing courses. Those documents do not exist, so somebody writes them from scratch every time. This tool writes the first draft.

The distinction that keeps this from colliding with the Assessment Engine: that tool recommends what already exists, this one produces what does not.
